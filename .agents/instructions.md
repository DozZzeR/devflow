# Project instructions

The set of coding guidance for this project. `AGENTS.md` and `CLAUDE.md` point here, so the
set travels with the repository and stays readable inside agent sandboxes.

Read the matching file at the start of a matching task. Do not load all of them unconditionally.

| Trigger | File |
|---|---|
| Writing, reviewing or refactoring TypeScript or JavaScript | `.agents/instructions/SOLID.instructions.md` |

Project-specific sets are added the same way: for example DDD for a backend, FDD for a frontend,
SOLID for all.
